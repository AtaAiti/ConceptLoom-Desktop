# P2: сохранённые объяснения

Desktop 0.3.3. Второй срез из [продуктового плана](notebooklm-product-review.md), поверх [P1](p1-source-tutor.md). В 0.3.4 добавлен [P3: вопрос об узле карты](p3-map-tutor.md). Следующая сессия — **P4: две карточки из фрагмента**, затем P5 → P6.

## Что получает пользователь

- Под ответом репетитора — «Сохранить объяснение» / «Убрать из сохранённых». Вопросы пользователя не сохраняются отдельно.
- В Учебном центре — список закладок активного пространства, от новых к старым. Первые 10 записей, «Показать ещё», фильтр по направлению, короткие превью.
- Просмотр полного ответа, исходного вопроса, направления и дат. Цитата открывается в существующем окне с номером страницы и сохранённым фрагментом. Доступны клавиатура, Escape, возврат фокуса и прежний переход к репетитору из цитаты.
- После удаления/изменения источника остаётся прежний snapshot с предупреждением. Новый запрос по устаревшему фрагменту по-прежнему блокируется P1.
- Пустой список объясняет действие и ведёт к репетитору. Во время записи кнопка заблокирована. Ошибка записи оставляет прежнее состояние, показывает причину и позволяет повторить действие.
- Снятие закладки сохраняет переписку и открытый просмотр. Удаление направления/пространства удаляет его переписку и закладки; это обозначено в списке и подтверждении удаления направления.

## Как устроено

`types/state.ts` добавляет необязательный ISO `savedAt` в существующий message. Старые сообщения валидны без него; repository запрещает закладки на user-сообщениях. Версия состояния остаётся 2. Новых SQL-таблиц, зависимостей и миграций нет: SQLite хранит JSON payload сообщений, включая citations.

`features/tutor/savedExplanations.ts` выбирает только assistant-закладки активного пространства и меняет конкретный ответ по workspace/course/message IDs в последнем состоянии очереди commit. Устаревший объект ответа не записывается обратно: новые content/citations не перетираются, удалённая запись не восстанавливается, поздняя запись остаётся в исходном пространстве. Повторное сохранение не меняет дату первой закладки.

`SaveExplanationButton.tsx` разделяется между Tutor и просмотром Study Hub; обновление только после успешной записи. `features/dashboard/SavedExplanations.tsx` использует существующие Panel, Dialog и Citations. Из App передаётся прежний scoped commit.

Сохранение не вызывает ИИ: **0 inference, $0 API**, работает без Ollama и облачного входа. Не создаёт источники, attempts, FSRS reviews или mastery. Исходный AI-ответ не становится проверенным первичным материалом.

## Проверка

Результат: **41 TypeScript unit + 15 native Rust + 21 production-browser E2E passed**. 3 opt-in проверки ИИ в Vitest и 1 аккаунтная проверка в Rust не запускались. TypeScript/build и Rust format прошли. Проверены оба оформления; при ширине 1000 px горизонтального переполнения нет. P2-сценарии подтвердили 0 запросов chat.

Из каталога `desktop`:

```powershell
npm test
npm run build
$env:PLAYWRIGHT_PREVIEW = '1'
npx playwright test --workers=1 --reporter=line
cd src-tauri
cargo fmt --check
cargo test --lib
```

Unit: старые данные, round-trip savedAt, сохранение citations/FSRS, targeted patch, идемпотентность, удалённый ответ/курс, поздняя запись при переключении пространства, изменённые/удалённые источники, cascade.

Native SQLite: сохранение → закрытие БД → повторное открытие → снятие закладки без удаления ответа/цитат → cascade при удалении направления. Тест работает с временной БД, пользовательские данные не затрагиваются.

Browser: сохранение → reload → список → полный ответ → вложенная цитата → снятие закладки; ошибки сохранения/снятия и retry; snapshots после удаления/редакции источника; фильтр/пагинация/изоляция; клавиатура; тёмная тема 1366×768 и светлая 1000×700. Запросы chat перехватываются счётчиком: сценарии P2 ожидают 0.

Ручная приёмка: открыть ответ в репетиторе → сохранить → перезапустить приложение → Учебный центр → открыть ответ и цитату → убрать закладку → проверить, что исходный ответ остался в переписке. Повторить без запущенного Ollama.

Установщик: `desktop/releases/ConceptLoom_0.3.3_x64-setup.exe`. Он не запускается поверх пользовательской установки автоматически.

## Границы среза

Закладка связана с исходной перепиской, не независимая заметка. Редактирование, экспорт и индексация объяснений не добавлены. Неотправленный черновик вопроса сохраняет прежние правила P1: переживает навигацию в текущем запуске, но не перезапуск. Автоматической проверки истинности AI-ответа нет; предупреждение об изменении источника сравнивает сохранённый текст и страницу с текущим фрагментом.
