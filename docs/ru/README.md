## ConceptLoom Desktop 0.3.7

Независимое desktop-приложение и форк [Zproger/ConceptLoom](https://github.com/Zproger/ConceptLoom).
Исходное указание авторства MIT сохранено в [LICENSE](../../LICENSE).

Windows-приложение для обучения по своим материалам: пространства и библиотеки,
карта понятий, занятия с проверкой понимания, репетитор, Учебный центр и
FSRS-повторение карточек. Интерфейс CAPYBARA поддерживает светлую и тёмную темы.
Данные хранятся локально в SQLite.

ИИ можно запускать через Ollama (`qwen3:4b` по умолчанию) или подключить ChatGPT,
Claude либо Gemini через официальный клиент и существующий аккаунт. Для
аккаунтного режима нужны интернет, согласие на передачу контекста и доступ,
который принимает соответствующий сервис. Подписка не гарантирует доступ ко всем
моделям. [Подключение и конфиденциальность](../account-providers.md).

**Текущая версия исходников — Desktop 0.3.7 в `main`.** Основная ветка содержит
все шесть MVP P1–P6 и актуальную документацию. Независимый MCP-пакет сохраняет
версию 1.1.0. [История реализации и проверок](../notebooklm-product-review.md).

### Реализованные сценарии

- Импорт PDF, TXT, Markdown и скопированного текста; локальный поиск по отрывкам.
- **P1:** «Разобрать с репетитором» на странице или в цитате — точный фрагмент и
  редактируемый вопрос, который отправляется только по кнопке.
- **P2:** закладки ответов в Учебном центре с сохранёнными цитатами.
- **P3:** вопрос из выбранного узла карты с контекстом его предпосылок.
- **P4:** два черновика карточек из отрывка, ручная правка и выбор перед добавлением
  в повторение.
- **P5:** обзор выбранного раздела — три тезиса, три термина и три вопроса, точные
  страницы, кэш и пометка об устаревшем тексте.
- **P6:** сравнение двух понятий по трём критериям с подтверждениями для каждой
  стороны и явными пробелами поиска; результат остаётся в беседе и доступен для закладки.

Чтение и генерация объяснений не повышают освоение темы автоматически. Его
определяют проверки и повторение. [Подробности всех шести этапов](../notebooklm-product-review.md).

### Запуск текущей desktop-версии

Нужны Node.js 22, Rust stable с MSVC, Visual Studio C++ Build Tools, Windows SDK
и WebView2. Разработка и сборка проверялись на Windows; подробности — в
[desktop-руководстве](../../desktop/README.md#windows-requirements).

```powershell
git clone https://github.com/AtaAiti/ConceptLoom-Desktop.git
cd ConceptLoom-Desktop/desktop
npm ci
npm run desktop
```

Для локального ИИ отдельно установите Ollama и выполните `ollama pull qwen3:4b`.
Для аккаунта выберите провайдера в Настройках и пройдите вход через его клиент.
Сборка установщика: `npm run package` из `desktop`; результат находится в
`desktop/src-tauri/target/release/bundle/nsis/`. Папка локальных сборок
`desktop/releases/` игнорируется Git, установщики не входят в исходники.

Desktop импортирует PDF с текстовым слоем, TXT/Markdown и вставленный текст.
OCR, прямой импорт EPUB/аудио/видео и автоматический обзор целой книги не реализованы.
Обзор P5 ограничен 1–5 страницами, 7 200 символами и шестью отрывками; P6 использует
до трёх найденных отрывков на сторону. Нативное приложение и browser preview хранят
данные отдельно. [Полные инструкции и ограничения](../../desktop/README.md).

## Исходный MCP-процесс — 1.1.0

**Переносимый AI-подход к обучению для Codex, Claude Code, OpenCode и DeepSeek Harness.**

MCP-пакет использует Node.js 20+ и запускается внутри coding-клиента. Его версия,
настройка и учебные файлы независимы от Desktop; для запуска приложения этот
адаптер устанавливать не нужно.

Concept Loom превращает coding-агента в структурированного учебного партнёра. Вместо немедленной длинной лекции AI помогает определить полезную цель, найти границу понимания, предложить короткий маршрут зависимостей и проходить по одной связи за раз.

```text
цель → граница знаний → карта → одна связь → проверка → перенос
```

Подход работает для совершенно новых тем и для ваших книг, курсов, заметок, кода и транскриптов.

### Зачем это нужно

- Учиться ради практического результата, а не обзора всей дисциплины.
- Находить пробелы и заблуждения до построения следующих идей.
- Проверять понимание вопросами со скрытым ответом.
- Отдельно проверять узнавание, воспроизведение, применение и перенос.
- Возвращаться к понятиям через интервальное воспроизведение между сессиями.
- Сохранять компактный Markdown-конспект между сессиями.
- Использовать один подход в четырёх поддерживаемых клиентах.

### Быстрый запуск с Codex

Нужны Node.js 20+ и Codex CLI.

```bash
node scripts/setup.mjs codex --target /путь/к/учебной-папке
cd /путь/к/учебной-папке
codex
```

Установщик сам вычисляет путь и регистрирует MCP-сервер в Codex. Флаг `--skip-mcp` позволяет установить только файлы workspace, не меняя глобальную MCP-конфигурацию.

После обновления Concept Loom обновите уже установленный skill командой `node scripts/setup.mjs codex --target /путь/к/учебной-папке --refresh`.

Первый запрос:

```text
Используй $concept-coach. Я хочу понять транзакции в базах данных настолько,
чтобы выбирать подходящий уровень изоляции для небольшого веб-приложения.
```

### Другие клиенты

```bash
node scripts/setup.mjs claude-code --target /путь/к/учебной-папке
node scripts/setup.mjs opencode --target /путь/к/учебной-папке
node scripts/setup.mjs deepseek-harness --target /путь/к/учебной-папке
```

Для DeepSeek Harness установщик создаёт нативный project skill и отдельный MCP patch. Запускайте Harness из учебной папки так:

```bash
npx @deepseek-ai/dsh --profile web --patch .dsh/concept-loom.patch.yml
```

DeepSeek Harness пока находится в developer preview, поэтому его формат конфигурации может меняться. Флаг `--skip-mcp` устанавливает только `.dsh/skills/concept-coach`, если MCP-сервер вы подключаете через собственный профиль Harness.

Первичная установка не перезаписывает существующую конфигурацию и может создать
дополнительный файл инструкций для ручного объединения. `--refresh` обновляет
управляемый skill (и patch DeepSeek Harness), а не всю конфигурацию workspace.

У MCP-пакета нет runtime-зависимостей npm. Небольшие структуры показываются текстовыми схемами прямо в терминале, а более крупные карты — блоками Mermaid, которые также можно сохранить в Markdown-конспект.
